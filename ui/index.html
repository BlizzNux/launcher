Set up Battle.net

      
    
      
    Battle.net isn't installed in the launcher's prefix yet. Pick one:
    
      
    
        
    
          Install Battle.net
          Downloads the official installer from Blizzard and runs it. Sign in when it asks,
            let it finish, then close Battle.net. Takes a few minutes.
        
    
        
      
    
      
    
        
    
          I already have Battle.net on this computer
          Point the launcher at an existing prefix from Steam, Lutris or Bottles.
            Your games stay where they are; nothing is downloaded again.
